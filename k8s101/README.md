# Introduction 
Training project for Kubernetes101 course at Alten 

# Getting Started
1.	Make sure the following apps are installed: 
    Visual Studio or Visual Studio Code
    lens (optional)
    either Docker & docker-compose for Windows/linux or remote VM with ssh-access and the following installed:
        git
        kubectl
        azure cli
        kompose
        remote-ssh for visual studio code (extension)(optional)
    for home assignement (part3, not mandatory)
        minikube

2.	Clone or download this repository locally
3.	Make sure you can access the VM assigned by trainer or have Docker and docker-compose installed
4.	Have fun learning!
